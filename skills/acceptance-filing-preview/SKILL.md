# 竣工验收组织与备案（试用版）

## 定位

覆盖从"能不能验"到"备案办结"的完整链路：

**验收条件核对 → 验收组组建与验收会议 → 竣工验收报告 → 专项验收衔接 → 备案**

服务对象是建设单位（业主方）的工程管理人员，项目类型以污水处理厂、污水收集管网、提升泵站为主。

## 开工前必须问清的五件事

缺一项就不要往下做，一次性问完：

1. 哪个项目、哪个单位工程或标段
2. 现在要解决哪一步：能不能验 / 组织会议 / 出报告 / 专项验收 / 备案
3. **验收合格日是哪天**（备案时限从这天起算）
4. 属地住建或水务部门有无额外材料要求
5. 要交付什么：核对表 / 材料清单 / 时限推算 / 报告框架

## 一、验收条件核对

依据《建设工程质量管理条例》（国务院令第 279 号）第十六条，竣工验收应当具备：

| 序号 | 条件 | 常见问题 |
|---|---|---|
| 1 | 完成设计和合同约定的各项内容 | 甩项工程未办理手续 |
| 2 | 有完整的技术档案和施工管理资料 | 资料后补、签字不全 |
| 3 | 有主要建筑材料、构配件和设备的进场试验报告 | 缺复试报告 |
| 4 | 有勘察、设计、施工、监理单位分别签署的质量合格文件 | 签字人无授权 |
| 5 | 有施工单位签署的工程保修书 | 保修期与合同不一致 |

五项齐全之前，验收会议不具备召开条件。

## 二、验收组与验收会议

- 验收组由建设、勘察、设计、施工、监理五方组成
- 组长由建设单位项目负责人担任
- 会议须形成验收记录，五方签字确认
- 验收结论分为：合格 / 不合格需整改

会议材料准备清单：验收方案、五方报告、质量评估报告、监督报告、影像资料。

## 三、备案材料与时限

依据《房屋建筑和市政基础设施工程竣工验收备案管理办法》（建设部令第 78 号，2009 年住建部令第 2 号修正）：

**建设单位应当自竣工验收合格之日起 15 日内，向备案机关备案。**

备案材料通常包括：

| 序号 | 材料 |
|---|---|
| 1 | 工程竣工验收备案表 |
| 2 | 工程竣工验收报告 |
| 3 | 规划部门出具的认可文件或准许使用文件 |
| 4 | 消防部门出具的验收合格文件 |
| 5 | 环保部门出具的验收合格文件或准许使用文件 |
| 6 | 施工单位签署的工程质量保修书 |
| 7 | 法规规章规定必须提供的其他文件 |

完整的 16 项清单（含各地增项）在完整版中提供。

## 四、专项验收衔接

竣工验收不是终点，以下专项必须先完成或同步推进，否则备案会被卡：

- 规划核实
- 消防验收或备案
- 竣工环保验收
- 城建档案预验收
- 排水主管部门的接入手续（污水厂与管网项目特有）

## 五、竣工验收报告框架

1. 工程概况（建设规模、投资、开竣工日期）
2. 建设程序执行情况
3. 参建单位与验收组织
4. 质量评定情况
5. 专项验收完成情况
6. 验收结论
7. 附件清单

未核实的数据标注【待核：说明】。

## 试用版与完整版的差别

| 项目 | 试用版 | 完整版 |
|---|---|---|
| 验收条件 | 5 项要点 | 逐条判断标准 + 缺项处置 |
| 备案材料 | 7 项常见 | 16 项完整清单 + 属地增项 |
| 时限推算 | 规则说明 | 自动推算表（含节假日） |
| 报告 | 结构框架 | GB/T 9704 版式 Word 可直接出件 |
| 属地差异 | 未覆盖 | 支持按地区定制清单 |

完整版获取方式见仓库 README。

## 使用边界

各地备案要求存在差异，**以属地住建或水务部门的最新清单为准**。本技能输出为工作底稿，不替代主管部门的正式审查。
